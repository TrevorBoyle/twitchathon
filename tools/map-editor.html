Load a different location set…

This map defaults to the South Australian site set from the game. To build a map for somewhere else, paste the SITES export from the location editor tool (or the SITES block straight out of index.html) below. Any location whose id already has a spot on the map keeps it; brand-new ones are dropped in a fresh circle for you to drag into place. Roads pointing at a location that's no longer in the set are removed. You can also paste a SITE_POSITIONS block here on its own (e.g. one you already worked out elsewhere) to move existing markers straight to those coordinates, matched by id, without changing anything else.
