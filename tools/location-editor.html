Location Editor

Add, edit and delete the locations that make up the Twitchathon map — their name, real eBird hotspot, camp/hide/water flags, blurb, and the list of species on offer there. Starts loaded with the game's current South Australian set; clear it out and build a fresh set for anywhere eBird has hotspots — Victoria, England, wherever — using the same rules, then export and paste back into index.html. Once you've got a location list, head to the map editor to place it on the map and wire up roads.
